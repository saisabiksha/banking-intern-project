# Banking System

## Project Description

A simple console-based Banking System developed using Python. It allows users to create an account, login, check balance, deposit money, withdraw money, transfer money, view transaction history, change PIN, and logout.

## Features

* Create Account
* Login
* Check Balance
* Deposit
* Withdraw
* Transfer
* Transaction History
* Change PIN
* Logout
* Input validation
* Account data persistence using accounts.json

## Technologies Used

* Python
* JSON

## How to Run

1. Open the project folder in VS Code or Antigravity.
2. Open the terminal.
3. Run:
   ```bash
   python banking_system.py
   ```

## Project Files

* banking_system.py — Main banking system program
* accounts.json — Stores account data and transaction information
* README.md — Project documentation

## Important Note

This is an educational mini-project. It uses a local JSON file for data storage and is not intended for real banking use.
